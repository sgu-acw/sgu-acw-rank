## 一学年有哪些比赛

按时间顺序大致是：

| 赛事 | 形式 |
| --- | --- |
| XCPC 区域赛 | 三人一队 |
| 百度之星 | 单人 |
| 蓝桥杯 | 单人 |
| 天梯赛 | 十人一队 |
| XCPC 邀请赛 | 三人一队 |
| 马蹄杯 | 单人 |

XCPC 一般指 ICPC、CCPC 及其衍生赛事；说「ACM 比赛」时一般就是指 ICPC。另外 CCPC 有一场独立的女生赛。

除 XCPC 三人一队、天梯赛十人一队外，其余都是单人参赛。**不用自己组队**，届时会安排。

## 打算法竞赛有什么好处

- 加创新学分、综测，比赛期间有公假
- **所有比赛全部报销**，甚至可以公费去全国各地打比赛
- 有一定成绩后，对转专业有帮助
- 奖牌证书对以后找工作有帮助

## 怎么参加

### 想打蓝桥杯、天梯赛

积极学习编程语言和基本算法就行。**下学期初期有一场选拔赛**，会选出公费参加蓝桥杯的名额，以及（公费）参加天梯赛的资格，届时群里会发报名通知。

往年名额：天梯赛 30—40 人，蓝桥杯 50—60 人，机会很大。

顺带一提，蓝桥杯省奖十分简单，有分就有奖，过了选拔基本就稳省奖了。

### 想打 XCPC

需要：

1. 注册 Codeforces
2. 尽可能多完成之后集训的题目，包括本次测试赛
3. 尽可能多来工作坊混个脸熟

届时会参考集训成绩、Codeforces 成绩和活跃度选拔队员。本学期可能有一次打星名额，给成绩优异的同学体验。

## 用什么语言

- **只打蓝桥杯**：建议 Python 或 Java，这两个赛道往年相对简单。去年蓝桥杯 Python 组和 Java 组分别拿了十二个和八个国奖，C++ 组只拿了两个，而且往年我们学校都没在 C++ 组拿过国一。
- **打 XCPC 和天梯赛**：建议 C++ 和 Python 都学，只学一个的话优先 C++。

当然这只是最佳实践。赛场上无论 C++、Python、Java，甚至你喜欢用 C 手搓数据结构都好，**只要能过题就是对的**。

## 训练纪律

请不要过度依赖 AI。用 AI 的前提是：**做完这道题后，关掉 AI 依旧能自己写出来**。我们会严查 AI。

## 常见问题

**零基础能不能来？**
可以。大部分在役成员都是零基础，我队友入学时啥也不会，现在拿了十多个国奖。

**非计算机专业的可以来吗？**
可以，欢迎，而且对转专业会有帮助，欢迎大家转来信工。

**没选上公费名额能自费吗？**
蓝桥杯可以，XCPC 和天梯赛不行。

**比赛和课程冲突咋办？**
有公假条。
